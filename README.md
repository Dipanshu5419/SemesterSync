
# SemesterSync

### Your Academic Command Centre

SemesterSync is an academic productivity and semester-tracking website designed to help students organise their subjects, track syllabus completion, manage study resources, revise through flashcards, and plan their weekly schedules.

## Features

- **Dashboard:** View overall academic progress and subject-wise statistics.
- **My Subjects:** Explore all semester subjects and monitor completion.
- **Chapter Tracker:** Track individual topics and save completed chapters.
- **Notes Library:** Access organised study materials and resources.
- **Flashcards:** Reveal answers to support active revision.
- **Study Planner:** Use a ready-made weekly schedule or create and save a personalised study plan.
- **Theme Switcher:** Choose between Current, Dark, and Light themes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Navigate through the different sections using the sidebar.

No additional installation is required.

## Data Storage

SemesterSync uses browser Local Storage to save information such as:

- Chapter completion progress
- Study planner tasks
- Custom study schedules
- Selected theme preference

**Note:** Saved information is stored locally in the browser and is not automatically synchronised across devices.

## Deployment

SemesterSync can be hosted using GitHub Pages.

## Project Goals

The goal of SemesterSync is to provide students with a simple, organised, and accessible platform for managing their academic workload throughout a semester.
